# Engineering Portfolio Template

A responsive portfolio for energy-storage firmware, power-electronics controls, BESS integration, and grid-connected converter work.

## Included

- Technical, recruiter-friendly landing page
- Evidence-oriented project cards with honest status labels
- Interactive virtual-synchronous-generator response lab
- Experience, direction, capabilities, and contact sections
- Responsive navigation and mobile layout
- Custom favicon
- GitHub Pages deployment workflow

## Personalize before publishing

Replace bracketed placeholders in `index.html` with information you explicitly want public:

- Name and location
- Public contact links
- Verified employment and education dates
- Non-confidential project details
- Measured results and exported plots
- Repository and demonstration links

Do not publish employer-confidential material, licensed PSCAD libraries, or course-provided files as original work.

## Local preview

Open `index.html` directly, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

After merging the portfolio branch:

1. Open **Settings → Pages**.
2. Select **GitHub Actions** as the source.
3. Push to `main` or manually run the included deployment workflow.

Expected project-site URL:

`https://karan201996.github.io/embedded-portfolio-site/`
